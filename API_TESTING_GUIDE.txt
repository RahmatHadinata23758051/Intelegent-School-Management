API TESTING REFERENCE

TEST SEQUENCE FOR COMPLETE WORKFLOW:
====================================

Prerequisites:
- Backend running: php artisan serve (http://localhost:8000)
- Frontend running: npm run dev (http://localhost:5173)
- Postman or similar API client
- Database seeded with sample data

1. AUTHENTICATION TESTS
======================

Login with seeded credentials:
POST http://localhost:8000/api/login
Content-Type: application/json

{
  "email": "admin@isms-ewa.local",
  "password": "password"
}

Response (save token):
{
  "success": true,
  "message": "Login successful",
  "data": {
    "user": {
      "id": 1,
      "name": "Admin User",
      "email": "admin@isms-ewa.local",
      "role": "admin"
    },
    "token": "YOUR_TOKEN_HERE"
  }
}

Add token to header for subsequent requests:
Authorization: Bearer YOUR_TOKEN_HERE

Get current user:
GET http://localhost:8000/api/me
Authorization: Bearer YOUR_TOKEN_HERE

2. STUDENT TESTS
================

Get all students:
GET http://localhost:8000/api/students
Authorization: Bearer YOUR_TOKEN_HERE

Response includes risk_score with total_score and risk_level

Get single student with full details:
GET http://localhost:8000/api/students/1
Authorization: Bearer YOUR_TOKEN_HERE

Filter students by high risk:
GET http://localhost:8000/api/students/risk-level?level=high&limit=10
Authorization: Bearer YOUR_TOKEN_HERE

Create new student:
POST http://localhost:8000/api/students
Authorization: Bearer YOUR_TOKEN_HERE
Content-Type: application/json

{
  "name": "New Student",
  "email": "newstudent@example.com",
  "student_id": "STU999",
  "class_id": 1
}

Response: 201 Created with student data and initial risk_score

3. GRADE TESTS (TRIGGERS SCORING)
==================================

Get student's grades:
GET http://localhost:8000/api/students/1/grades
Authorization: Bearer YOUR_TOKEN_HERE

Create grade (AUTOMATIC RISK UPDATE):
POST http://localhost:8000/api/students/1/grades
Authorization: Bearer YOUR_TOKEN_HERE
Content-Type: application/json

{
  "subject": "Physics",
  "score": 92,
  "semester": "1",
  "academic_year": "2024"
}

Response: 201 Created
Notice: "message": "Grade created successfully and risk score updated"

Verify risk score updated:
GET http://localhost:8000/api/students/1
Authorization: Bearer YOUR_TOKEN_HERE
Check response.data.risk_score.total_score

Update grade (AUTOMATIC RISK UPDATE):
PUT http://localhost:8000/api/students/1/grades/1
Authorization: Bearer YOUR_TOKEN_HERE
Content-Type: application/json

{
  "score": 75
}

Response: 200 OK
Notice: Risk score recalculated

Delete grade (AUTOMATIC RISK UPDATE):
DELETE http://localhost:8000/api/students/1/grades/1
Authorization: Bearer YOUR_TOKEN_HERE

Severity levels for testing:
- "minor" → +5 risk points
- "moderate" → +15 risk points
- "major" → +30 risk points
- "severe" → +50 risk points

Multiple violations cumulative effect:
POST (create another violation)
POST (create another violation)
GET /api/students/1 (risk score increases each time)

6. ERROR HANDLING TESTS
=======================

Unauthorized (no token):
GET http://localhost:8000/api/students
Expected: 401 Unauthorized

Invalid token:
GET http://localhost:8000/api/students
Authorization: Bearer invalid_token
Expected: 401 Unauthorized

Not found:
GET http://localhost:8000/api/students/99999
Authorization: Bearer YOUR_TOKEN_HERE
Expected: 404 Not Found

Validation error (missing required field):
POST http://localhost:8000/api/students
Authorization: Bearer YOUR_TOKEN_HERE
Content-Type: application/json

{
  "name": "Student"
}

Expected: 422 Unprocessable Entity
Response includes errors for missing email, student_id, class_id

Invalid score (outside range):
POST http://localhost:8000/api/students/1/grades
Authorization: Bearer YOUR_TOKEN_HERE

{
  "subject": "Math",
  "score": 150,
  "semester": "1",
  "academic_year": "2024"
}

Expected: 422 Validation Error

RISK SCORE CALCULATION TEST
============================

Starting state:
Student 1 - risk_score: 0

Add grade (85 score):
Academic = 10 points
Total = 10 * 0.6 = 6 points
Risk level = low

Add violation (moderate):
Behavioral = 15 points
Total = (10 * 0.6) + (15 * 0.4) = 6 + 6 = 12 points
Risk level = low

Add violation (severe):
Behavioral = 15 + 50 = 65 average
Total = (10 * 0.6) + (65 * 0.4) = 6 + 26 = 32 points
Risk level = medium

Add low grade (60 score):
Academic = 50 points
Total = (50 * 0.6) + (65 * 0.4) = 30 + 26 = 56 points
Risk level = high

  }'

POSTMAN COLLECTION SETUP
=========================

Base URL: {{base_url}} = http://localhost:8000

Variables:
- base_url: http://localhost:8000
- token: (set after login)

Pre-request Script (auto set token):
var loginResponse = pm.response.json();
pm.environment.set("token", loginResponse.data.token);

All requests should have:
Authorization: Bearer {{token}}
